# DrishtiSaathi: ZEISS hackathon pitch kit

## Open in Claude Code
Unzip, then run `claude` inside this folder. `CLAUDE.md` gives it the full context (idea, site structure, rules, open issues).

## Run the site
```bash
cd site
npm install
npm run dev        # open http://localhost:5173
```
Needs Node 18 or newer. `npm run build` makes `site/dist/index.html`, a single file you can open or host anywhere.

Want to see it without installing anything? Open `prebuilt/drishtisaathi-site.html` in Chrome.

## Present / record
Chrome, fullscreen (F), 1920×1080. Put your webcam bubble on the dashed circle in the bottom-right.
→ next · ← back · C camera guide · V move guide · H hide HUD · F fullscreen.
Click "Your team name" on the first and last scenes to type your team name.
